# Data source catalog (geoservices)

`catalogo/geoservicos/` is the source seed that ships with the repository, a
vault of Markdown notes: one folder per institution, with the institution's note, the
list of layers and the attributes of each layer. The API imports this folder at startup and turns each
WFS layer into a platform **data source** (table `fontes_de_dados`), which
the assistant consults BEFORE hunting for any external data — see
`docs/sources.md`.

Nothing here is read by the interface: the catalog feeds the MCP tools
`search_sources` / `describe_source` and the validation warnings.

## Where the content comes from

The layer names, titles, descriptions and attribute schemas are the ones
each service publishes in `GetCapabilities` and `DescribeFeatureType`, collected
on the date of each note. That content belongs to each institution and follows the terms of the
originating service (many are open government data; check the terms
before republishing a clip). What belongs to Atlans: the organization into notes, the
purposes, the synonyms and the usage tips.

## What the folder contains

```
catalogo/
  README.md                     ← this file
  geoservicos/
    _sinonimos.md               ← optional: synonyms for search (root)
    <Instituição>/
      <Nome — SIGLA>.md         ← the institution's note (or nota-base.md)
      Camadas.md                ← the layers by group
      Atributos.md              ← the attributes of each layer
```

Only first-level subfolders are read; loose files at the root (indexes,
reports) are ignored — except `_sinonimos.md`. Names are kept in NFC.

## Today's format (generated by the Vault script)

**Institution note** — the name comes from the `# título`; the fields are bullets
`- **Campo:** valor`:

```markdown
# Fundação Nacional dos Povos Indígenas — FUNAI

- **Mantenedor:** Funai
- **Finalidade:** Terras indígenas, aldeias e coordenações regionais.
- **Endpoint WFS:** <https://geoserver.funai.gov.br/geoserver/ows>
- **GetCapabilities:** <https://geoserver.funai.gov.br/geoserver/ows?service=WFS&request=GetCapabilities>
- **Versão usada para os schemas:** WFS 2.0.0
- **Última coleta de metadados:** 2026-09-17
- **Camadas inventariadas:** 12

Parágrafo livre sobre o serviço.

> [!tip] Como consumir no Atlans
> Nó WFS → url = endpoint acima, typeName = a camada.
```

- `Endpoint WFS` is **required**: without it the folder is ignored with the reason
  `sem_endpoint_wfs` (this is what happens today with the ArcGIS REST folders and with the
  "(Metadados em validação)" (Metadata under validation) placeholders — they are left for a future phase).
- `Versão usada para os schemas` (version used for the schemas): `WFS 2.0.0` (default) or `WFS 1.0.0` (IBGE).
- A URL with an embedded username and password is refused (`url_com_credencial`).
- `Finalidade` (purpose) becomes the layers' description; the free paragraph and the callout
  become the `dicas` (tips).

**`Camadas.md`** — `## Grupo (n)` groups and `` - `ns:camada` — Título `` bullets:

```markdown
## Funai (12)
- `Funai:tis_poligonais` — Terras indígenas (poligonais)
- `Funai:aldeias_pontos` — Aldeias (pontos)
```

**`Atributos.md`** — `### `ns:camada`` followed by the table
`| Campo | Tipo XSD | Nulo | Ocorrência |`. The row whose type is
`gml:<Geometria>PropertyType` defines the geometry column and type. The first
column among `gid, fid, id, objectid, ogc_fid` becomes the suggested `sortBy` (
GeoServer requires a SORTBY to paginate a layer without a primary key).

## Optional extensions (backward-compatible)

Today's format is already importable. What limits SEARCH is the layer title:
`BC100_AC_2023_Barragem_P` does not say "barragem" (dam) to someone looking for "represa" (reservoir), and
nothing says the country, the state (UF) or which of 40 similar layers is the preferred one. Three
additions, all native to Obsidian, which the importer already reads:

1. **YAML frontmatter in the institution note** (Obsidian's "Properties").
   The body fields still apply; the frontmatter only makes explicit what
   the search needs:

   ```yaml
   ---
   sigla: FUNAI
   pais: BR
   uf:                # "MT" when the institution is state/municipal
   endpoint_wfs: https://geoserver.funai.gov.br/geoserver/ows
   versao_wfs: "2.0.0"
   temas: [terras indígenas, povos indígenas, territórios]
   prioridade: 1      # 1 preferred · 2 normal · 3 secondary
   coletada_em: 2026-09-17
   ---
   ```

2. **Inline tags on the layers** (`Camadas.md`), at the end of the line, for what the
   title does not say. They are removed from the title and go into the themes; `#preferida` marks
   priority 1 and `#secundaria` priority 3:

   ```markdown
   - `Funai:tis_poligonais` — Terras indígenas (poligonais) #terras-indígenas #polígono #br #preferida
   ```

   You do not need to tag everything: tagging the 200–300 layers that matter (fire
   hotspots, indigenous lands (TIs), conservation units (UCs), municipalities, hydrography, CAR, schools) already changes the search.

3. **`_sinonimos.md` at the root** — a `| termo | sinônimos |` table (or
   `- termo: a, b` bullets). The search expands the query with it, in addition to the service's default
   synonyms:

   ```markdown
   | termo | sinônimos |
   |---|---|
   | focos de calor | queimadas, incêndio, hotspot, fogo |
   | terra indígena | TI, indígena, aldeia |
   ```

## How the server uses the folder

- At API startup, `importar_catalogo_no_arranque()` (`app/core/fontes_catalogo.py`)
  reads `FONTES_CATALOGO_DIR` (default: this folder) and imports each layer as a platform
  `vault` source. It is idempotent: each record has a hash; a folder identical to the
  one at the last startup costs one query and zero writes. A layer that disappeared from the folder
  is marked as removed (soft delete). Only one worker imports (Redis lock).
- Right after, and then every `FONTES_VERIFICACAO_INTERVAL` seconds (default
  1 day; 0 turns it off), ONE GetCapabilities per distinct URL marks the layers
  of that URL as `ok` or `falhando` (failing) and fills in CRS and bbox.
- The parser is `app/services/fontes_vault.py`; the import and the search,
  `app/services/fontes_service.py`. The test fixtures in
  `tests/fixtures/vault/` are real excerpts of this folder.

## How to update

1. Export the Vault (the `Geosserviços/` folder) and replace the contents of
   `catalogo/geoservicos/` — without the loose files at the root, except `_sinonimos.md`.
2. Check locally:

   ```bash
   python -c "from app.services import fontes_vault as v; r=list(v.ler_pasta('catalogo/geoservicos')); print(len(r))"
   pytest tests/unit/test_fontes_vault.py tests/unit/test_fontes_service.py -q
   ```

3. Open a PR. The folder is excluded from `detect-secrets` and from the pre-commit file size
   limit (IBGE's `Atributos.md` is 4 MB).

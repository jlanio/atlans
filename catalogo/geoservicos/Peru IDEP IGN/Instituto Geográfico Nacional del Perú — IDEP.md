# Instituto Geográfico Nacional del Perú — IDEP

- **Mantenedor:** IGN (Perú)
- **Finalidade:** Infraestructura de Datos Geoespaciales Fundamentales del Perú: limites, cartografía básica e imagens.
- **Tipo de serviço:** ArcGIS Server (REST).
- **Catálogo REST:** <https://www.idep.gob.pe/geoportal/rest/services>
- **Serviços inventariados:** 88
- **Camadas inventariadas:** 753
- **WFS também disponível:** não verificado — use `HttpRequest` com `f=geojson`.
- **Última coleta de metadados:** 2026-09-17

> [!warning] Como consumir no Atlans
> Para as camadas sem WFS, use o nó `HttpRequest` com `f=geojson` na URL da camada e leve a saída adiante com `from_key:"body"`.
